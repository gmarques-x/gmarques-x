Fonts for the SVG cards, stored as base64 WOFF2 so `scripts/render.py` can embed them. GitHub shows README images without loading web fonts, so the fonts have to travel inside each SVG.

- JetBrains Mono (Regular and Bold, trimmed to printable ASCII plus a few symbols), for the figures. © The JetBrains Mono Project Authors, SIL Open Font License 1.1 (see `OFL.txt`).
- IM Fell English Italic and IM Fell English SC (Latin), for the surveyor's labels and notes. SIL Open Font License 1.1 (see `OFL-im-fell-english.txt`).
