Trimmed JetBrains Mono (Regular and Bold, printable ASCII plus a few symbols), stored as base64 WOFF2 so `scripts/render.py` can embed it in the SVG cards. GitHub shows README images without loading web fonts, so the font has to travel inside each SVG.
